# NM Nufail Portfolio

A complete, modern, responsive personal portfolio website built with HTML5, CSS3, and Vanilla JavaScript.

## 🚀 How to Run Locally

### Option 1: Simple Static Serving
1. Clone or download the directory.
2. Open `index.html` directly in your browser.
   *Note: Some browser security features might block local file access for certain scripts. Using a local server is recommended.*

### Option 2: Live Server (Recommended)
1. If you use **VS Code**, install the "Live Server" extension.
2. Right-click `index.html` and select **"Open with Live Server"**.

### Option 3: Python (If Python is installed)
1. Open your terminal in the project folder.
2. Run `python -m http.server 3000`.
3. Open `http://localhost:3000` in your browser.

### Option 4: NPM / Node.js (If using the provided package.json)
1. Run `npm install`
2. Run `npm run dev`
3. View the app at `http://localhost:3000`

## 📁 File Structure
- `index.html`: Main structure of the portfolio.
- `styles.css`: All styling including animations and dark theme.
- `script.js`: Interactive elements like smooth scroll and mobile menu.
- `ProfilePhoto.png` (optional): Place your profile photo in the project folder and update the path in `index.html`.

## 🛠 Features
- Dark Theme with Teal/Mint Accent
- Fully Responsive Design (Mobile, Tablet, Desktop)
- Smooth Scrolling Navigation
- Scroll-triggered Reveal Animations
- Contact Form UI
- Professional & Academic Projects Showcases
